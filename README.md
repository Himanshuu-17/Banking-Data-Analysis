# Banking-Data-Analysis
Project Overview
This project analyzes banking data using PostgreSQL, Excel, and Power BI to understand customer demographics, account balances, transaction, loans, and cards usage.

Business Objectives
- Analyze customer distribution across cities.
- Understand account balances and banking activity.
- Evaluate transaction amounts and transaction status.
- Analyze loan distribution and default patterns.
- Explore banking card data.
- Present key performance indicators through an interactive Power BI dashboard.

Tools & Technologies
- PostgreSQL : Data Querying, aggregation, Business analysis using filtering, grouping, aggregate functions, JOINs.
- Power BI : Dashboard design and data visualization.
- CSV/Excel :Dataset storage, data cleaning, and data preparation.

Key Analysis
-Customer Analysis
Analyzed customer distribution and banking data across different cities.

-Account Analysis
Explored account information and account balances.

-Transaction Analysis
Analyzed transaction amounts, payment modes, and transaction status.

-Loan Analysis
Examined loan distribution and default patterns across cities.

-Card Analysis 
Explored banking card information and related metrics.

-JOIN Analysis
Combined multiple banking tables to explore relationships between customers, accounts, transactions, loans, and cards.

Power BI Dashboard
The Power BI dashboard presents banking metrics and analysis in a visual format to make insights easier to understand.
